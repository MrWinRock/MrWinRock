# Portfolio fonts

Self-hosted variable fonts from the official Google Fonts repository, retrieved 2026-10-26. Both use the SIL Open Font License 1.1; their license files are included here.

- Sora: https://github.com/google/fonts/tree/main/ofl/sora — `sora-variable.ttf`, `Sora-OFL.txt`.
- Noto Sans Thai: https://github.com/google/fonts/tree/main/ofl/notosansthai — `noto-sans-thai-variable.ttf`, `NotoSansThai-OFL.txt`.

Sora supplies display lettering. Noto Sans Thai supplies body text and Thai glyph coverage. Fonts are loaded by `src/index.css`; there are no runtime Google Fonts requests.
