## About me

I'm a Computer Science graduate from Suan Sunandha Rajabhat University who enjoys turning ideas into deployed systems—from React frontends and Bun or .NET APIs to Docker services running on my own VPS.

During my software development internship at DevDee Thailand, I worked across React, .NET Core, and MySQL, contributing to UI components, backend services, integrations, debugging, and document-processing workflows.

- Building backend-focused web applications and APIs
- Exploring LLM applications, voice AI, cybersecurity, and system design
- Operating and monitoring a self-hosted Linux environment
- Interested in gaming, football, and motorsport outside of coding
